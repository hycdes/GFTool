# SKILL_gameplay — 少女前线2：追放 战斗规则

> 本文件描述本工具站进行数值计算所需遵循的游戏规则。用户会分次补充，逐步完善。

## 0. 基础设定

- 游戏类型：**美式战棋**，**回合制**。
- 流程：**我方角色按次序行动**，我方回合结束后，**敌方行动**。
- 术语约定：本文件中 **「角色」= 人形**。

## 1. 回合内 / 回合外（核心判定）

以我方的行动次序为准来划分「回合内」与「回合外」：

- **回合内**：某角色正在行动时，该角色可以释放技能；在此期间发生的（由该角色执行的）一切操作，都算作**该角色的回合内**。
- **回合外**：当某角色行动结束、轮到其他角色行动，乃至我方回合结束、敌方开始行动之后，再涉及此角色的一切操作，都算作**该角色的回合外**。

### 示例

我方有 3 个角色 A、B、C，按次序行动：

1. **A 行动**：A 可以释放技能 —— 此时算作 **A 的回合内**。
2. **A 行动结束**，轮到 **B、C 行动**；之后**我方回合结束**，**敌方开始行动**。
3. 在步骤 2 的整个过程中，A 执行的一切操作都叫 **A 的回合外**。

## 2. 属性计算（总属性）

数据源为四类属性：`基础属性`、`心智增域`、`心智螺旋-增效点位`、`心智螺旋-额外进阶收益`。总属性按下列方式合成：

- **攻击 = (四类中所有「攻击」数值之和 + 调度室攻击加成) × (1 + 所有「攻击加成」百分比之和)**
- **生命 = (四类中所有「生命」数值之和 + 调度室生命加成) × (1 + 所有「生命加成」百分比之和)**
- **防御 = (四类中所有「防御」数值之和 + 调度室防御加成) × (1 + 所有「防御加成」百分比之和)**
- 暴击、暴击伤害、稳态、行动力：直接取用（当前仅出现在「基础属性」）。

> 注意：**调度室加成是数值项**，归入「数字加法括号」内（与基础/心智增域等数值一起相加），因此**参与后续的百分比乘算**，不是结算末端的独立加法。

> 展示约定：攻击/生命/防御三项可点击展开，展开时**不写 sum**，按「(谁+谁+…+调度室) × (1+谁+…)」逐项写出，并在每个数字下方标注来源（如「基础攻击力」「心智增域」「心智螺旋」「额外收益」「调度室」）。

## 3. 调度室加成

按**定位/职业类型**提供固定数值加成（**数值项**，计入总属性的「数字加法括号」内，再参与百分比乘算）：

| 定位 | 攻击 | 生命 | 防御 |
|---|---|---|---|
| 防卫 | +168 | +720 | +270 |
| 尖兵 | +192 | +576 | +192 |
| 支援 | +183 | +618 | +240 |
| 火力 | +231 | +519 | +222 |

角色定位取自其标签第一位（如「支援」「火力」等）。该加成作为**数值项**计入总属性的「数字加法括号」，与四类数值一起相加后再乘百分比。

## 4. 武器与总属性

**专武识别**：某武器的「烙印」对应此人形（即「武器烙印 · X」，X = 人形名）且武器为**五星**时，该武器即此人形的专武。数据上等价于：武器 `rank === 5` 且 `bond.id === 人形id`。

**默认装备**：五星人形默认装备其专武；**四星人形无专武，默认不装备**（可手动选择）。武器选择**只列出与该人形枪种匹配的武器**（按人形标签第 2 位），面板仅保留「稀有度」筛选。

**武器属性并入人形总属性**：

- 武器的数值项（如「攻击」「生命」）→ 并入总属性公式的**数字加法括号**内。
- 武器的百分比项（如「攻击加成」）→ 并入**百分比求和**。
- 武器的「暴击」「暴击伤害」→ **直接加到**面板对应项（与其他来源相加）。
- 因此总属性为：`(人形数值 + 武器数值 + 调度室) × (1 + 人形百分比 + 武器百分比)`。

**展示**：攻击/生命/防御、以及**暴击/暴击伤害**均可点击展开；每个数字下方标注来源（基础攻击力 / 心智增域 / 心智螺旋 / 额外收益 / 武器 / 调度室）。注意部分人形的「心智螺旋-增效点位」会提供暴击或暴击伤害（双暴），展开时一并列出。

## 5. 位键（心智螺旋键）

人形的心智螺旋含四类键（数据取官网「心智螺旋」）：

- **契合键（好感键）**：每人形 1 个，**只能自己佩戴**，提供属性加成。好感 5 级每项 3%，9 级提升为 **4.5%（最大值）**，**默认按 4.5% 计**。
- **共键**：带属性加成，**可跨人形通用**；本版本默认每人只带自己的共键，另提供一个通用「共键·通用暴击」（攻击 3%、暴击 3%）。
- **固键**：每人形 6 个，**只能自己佩戴**；**暂不参与计算**（记录备用，后续伤害计算会用到）。
- **跃键**：部分人形拥有，**只能自己佩戴**，提供技能效果；**暂不参与计算**（记录备用）。

**佩戴槽位**（人形属性 panel 的「位键佩戴」，共 4 槽，与武器同排）：

1. 第 1 槽：自己的好感键（可卸下，但**选择项只有自己这一个**）。
2. 第 2–4 槽：共键。默认第 2 槽为自己的共键，其余两槽为空；可任选其他人形的共键或通用共键。

所有位键选择 panel **不含筛选选项**。

**攻爆满配**（「位键佩戴」下的复选框）：勾选后——
- 通用共键「共键·通用暴击」按 **攻击 / 暴击 / 暴击伤害 各 +5%** 计；
- 其他共键：若其原生属性包含「攻击 / 暴击 / 暴击伤害」中的任意一种，则**补全另外两种**，且这三项**都按 5%** 计。
（仅影响共键；好感键不受影响。默认不勾选。）

> 键的 `id` 与图标文件名格式：`<英文名>_<类型>[_序号]`，如 `igla_love`（好感键）、`igla_static_1..6`（固键）、`igla_common`（共键）、`igla_leap`（跃键）；英文名由人形编号去掉稀有度后缀并小写得到（如 `IglaSSR`→`igla`）。

**属性并入总属性**：所佩戴的「好感键 + 共键」的属性会计入——
- 「攻击 / 生命 / 防御」类 → 计入**百分比求和**；
- 「暴击 / 暴击伤害」类 → **直接加到**对应项。

于是总属性为：`(人形数值 + 武器数值 + 调度室) × (1 + 人形% + 武器% + 位键%)`；暴击 / 暴击伤害为各来源（基础 / 心智螺旋 / 武器 / 位键）之和。

## 6. 武器配件

每把武器可挂 **4 个配件**（与武器磁贴同排右侧，2×2 纯文字磁贴）：枪口、部件1、部件2、部件3。

- **枪口**：可从 8 项属性中**不重复**选择（最多 4 项）：攻击 +72、攻击加成 +11.4%、生命 +162、生命加成 +11.4%、防御 +48、防御加成 +11.4%、暴击 +15%、暴击伤害 +15%。
- **其他部件**：可从 7 项中不重复选择（最多 3 项），**不能选暴击伤害**。
- **默认配满**：
  - 枪口：攻击、暴击、暴击伤害、攻击加成
  - 部件1 / 2 / 3：攻击、攻击加成、暴击
- 每个部件的属性**按人形单独保存**（默认值与人形关联）。

**属性并入**：配件属性并入总属性（算法与武器/位键相同）——
- 「攻击 / 生命 / 防御」及其「…加成」→ 分别计入**数字加法**与**百分比求和**；
- 「暴击 / 暴击伤害」→ **直接加到**对应项。
- **统一展示**：多部件相同属性**合并求和后只显示一个数字**（如 4 个部件都加攻击 72 → 显示 288）。

于是总属性为：`(人形数值 + 武器数值 + 配件数值 + 调度室) × (1 + 人形% + 武器% + 位键% + 配件%)`；暴击 / 暴击伤害为各来源（基础 / 心智螺旋 / 武器 / 位键 / 配件）之和。

## 7. 铭契

人形属性 panel 中的「铭契」为**勾选项（默认勾上）**。勾上时提供 **+5% 攻击加成、+5% 生命加成、+5% 防御加成**，计入总属性的**百分比求和**（来源标注「铭契」）。勾选状态按人形单独保存。

### 徽记助益

「徽记助益」为勾选项（**默认不勾**）。勾上时提供 **+1 攻击、+1 生命、+1 防御**（数值项，计入数字加法括号、再乘百分比；来源标注「徽记助益」）。勾选状态按人形单独保存。

## 8. 拟态图谱与契合度

- **拟态图谱（游戏内叫「核心」）**：提供固定的 **攻击 / 生命 / 防御 数值项**（计入数字加法括号），每人形一个核心、等级 1–60（默认 60）。数值 = `⌈核心基础值 × 等级系数 ÷ 1000⌉`（系数见 `SKILL_gamedata.md`）。来源标注「拟态图谱」。
- **契合度（默契回馈）**：仅 **2–5 级**提供加成（1、6–9 级不加）；提供 **攻击 / 生命 / 防御 数值项**，因人而异（随人形基础属性缩放）。来源标注「契合度」。算法见 `SKILL_gamedata.md`。

这两项同武器/配件/调度室一样，是「数字加法括号」里的数值项，最后一起乘百分比。

## 9. 拟态图谱（生长数据 / 显像因子 / 显像形态）

拟态图谱是与人形「拟态核心」绑定的装备系统：

- 每个人形 1 个拟态核心（等级 1–60）。核心的显像形态随核心等级解锁：
  **初始胚胎、Lv10 幼苗、Lv20 花芽、Lv30 花蕾、Lv45 花苞、Lv60 花朵**（共 6 个阶段）。
- 核心周围有 **6 个生长数据槽位**，每个槽位有固定类型（防卫 / 尖兵 / 支援 / 火力），只能装备同类型生长数据。
- 生长数据提供 **2 条特化形态词条**：1 条**固定词条**（决定主名与槽位类型）+ 1 条**随机词条**（决定前缀，可为任意职业）。α / β / γ 对应 1 / 2 / 3 级。同名词条等级可叠加，但不超过上限（固定词条上限 6 级；随机词条上限 2 / 3 / 5 级不等）。
- **生长数据命名**：`随机词条前缀 · 固定词条主名 + 等级后缀`。固定词条决定主名（如「攻击强化」→「穹顶之花」），随机词条决定前缀（如「浊刻抗性」→「除湿」），组合为「除湿·穹顶之花γ」。
- 特化形态词条对应一种**显像因子**，类型由词条所属职业决定：防卫=蓝、尖兵=紫、支援=绿、火力=红。
  两类词条**每级各提供 1 点对应因子**，因此一件生长数据会同时提供两种类型的因子（固定类型 + 随机前缀类型）。
- 核心上有 6 条**显像形态**词条，各自要求指定类型与数量的显像因子，达标即激活，效果随阶段不同；需求因人形/核心而异。
- 配置表里每条显像形态存有 4 个因子需求，顺序为 防卫 / 尖兵 / 支援 / 火力，需求为表中原始数值。需求可以包含核心没有槽位的类型，需要靠随机词条前缀的跨类型因子来满足。
- 拟态图谱在属性面板中只计入核心的攻击 / 生命 / 防御数值项（算法见 §8）；生长数据与显像形态的效果暂不并入面板属性。
